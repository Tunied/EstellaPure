---
title: 地形
description: 一个 Terrain 组件,用高度图或噪声生成地面,按高度和坡度上色,并分块绘制、随距离降低细节。
---

地面是大多数 3D 场景里画得最大的东西,也是网格最不擅长的东西:相机近处三角形太多,而真正需要的地方又太少。`Terrain` 组件从一张高度网格生成它,并切成块,每块按多个细节层级构建,所以脚下的山丘画得很细,而地平线上的同一座山丘只有几百个三角形。

## 组件

给某个实体加一个 `Terrain` 组件。地形以该实体为中心;它的子实体就是这些块,在场景运行时(以及编辑器的场景视图里)生成,字段一变就重建。没有任何东西被烘焙,除了组件本身也没有任何东西被保存。

| 字段 | 作用 |
|---|---|
| `heightmap` | 一张图:红色通道是高度。如果绿色通道不全是灰,它被当作 16 位高度的低字节,所以导出到每通道 8 位 PNG 里的 16 位高度图也能保留精度。为空则用噪声生成地面。 |
| `sizeX`、`sizeZ`、`height` | 地形的世界尺寸,以及最高处地面的世界高度。 |
| `chunks` | 每边的块数。每块单独剔除和绘制,块越多剔除越好、绘制调用越多。 |
| `chunkCells` | 一块在最细层级时每边的格数。 |
| `lodLevels`、`detail` | 每块有几个层级(每级比前一级粗一半),以及细层级能延伸多远的倍率。 |
| `seed`、`frequency`、`octaves`、`persistence`、`ridged`、`resolution` | 噪声地面:换一个种子就是另一片地面;`ridged` 从起伏的丘陵到尖锐的山脊。 |
| `splatmap` | 一张图,四个通道是四个图层的权重。为空则按高度和坡度上色。 |
| `rockSlope`、`dirtHeight`、`snowHeight` | 地面要多陡才变成岩石,以及草地转为泥土、雪开始出现的高度。 |
| `layerColor0`–`3` | 草、泥土、雪、岩石:没有材质时地面绘制用的颜色。 |
| `material` | 用 **Terrain** 着色器的材质(见下)。为空则直接把图层颜色画在地面上。 |

## 图层与 Terrain 材质

四个图层是草、泥土、雪和岩石。每个顶点会得到它在每个图层上的权重,来自 splatmap 或来自那里有多高多陡,**Terrain** 着色器(`builtin:terrain`)把它们画出来:`u_layer0`–`3` 是纹理,`u_tint0`–`3` 是它们的颜色,`u_tile0`–`3` 是一次重复覆盖多少世界单位。纹理按*世界位置*平铺,所以图层从一块到下一块不会断开,岩石从三个方向投影,所以悬崖不会被拉成一团。`u_sharpness` 让接缝更硬,`u_macroVariation` 在草地上叠一层缓慢的变化,让草地不是同一块图案的反复。

## 细节层级如何工作

每块是每边 `chunkCells` 格的网格,再按一半、四分之一……一直到两格各构建一次。引擎自己的[细节层级](/docs/zh-cn/performance/level-of-detail/)按这块在屏幕上有多大来选择。两个层级不同的邻居在共用的边上顶点数不同,会留下裂缝;所以每块都有一圈**裙边**,从边缘垂下的一堵墙,使一块可以单独构建,换层级时也不必重建任何其他块。每个层级的高度和法线都读自同一个场,所以一块在变粗时光照保持不变,只有轮廓变化。

## 从代码里用

可以问地面某处有多高,用来把东西放上去:

```ts
import { TerrainsRes } from 'esengine';

const terrains = app.getResource(TerrainsRes);
const y = terrains.heightAt(x, z);       // 世界高度,没有地形的地方为 null
const n = terrains.normalAt(x, z);       // 那里的单位法线,或 null
```

## 限制

- **没有碰撞。** 地面只是被绘制,不被模拟:要把东西立在上面用 `heightAt`,物理刚体会穿过它,除非项目自己加碰撞体。
- **高度只是一个场。** Splat 权重是逐顶点的,精度就是最细层级的网格精度。
- **没有洞、洞穴或悬挑。** 高度场在每个位置只有一个高度。洞穴和桥是和它放在一起的网格。
- **`heightAt` 不考虑旋转。** 地形的位置和均匀缩放会被考虑,绕 y 的旋转不会。
- **块每帧构建几个**,所以大地形会在一小会儿内出现,而不是卡住某一帧。
