水有两半。**Water 着色器**(`builtin:water`)是外观:折射、水深、反射、泡沫。**`WaterBody` 组件**是水体本身:它构建几何体,用波浪抬起它,并让代码能查询它的表面,所以脚本读到的就是画出来的。本章两者都讲,也讲还没有的部分。

水是一个可选模块:只有场景里有 `WaterBody`(或脚本导入了 `esengine/water`)时,包才会带上它,所以 2D 游戏不带任何水的代码。

## 组件

给某个实体加一个 `WaterBody`。实体决定水的位置和倾斜;它的子实体是网格,在场景运行时生成,形状一变就重建。

| 字段 | 作用 |
|---|---|
| `form` | **海洋**:没有边,跟随相机。**湖泊**:以实体为中心、`sizeX` × `sizeZ` 的矩形,或 `boundary` 给出的轮廓。**河流**:沿同一实体上的 `Spline`。 |
| `flowSpeed` | 河流的流速,世界单位每秒,指河面最宽处的流速。 |
| `boundary` | 湖泊的轮廓:它自己的 xz 平面上围一圈的三个或更多点。留空就是矩形。 |
| `shoreWidth` | 从岸边往里多远、水多深,波浪才长到完整高度。0 表示波浪一直完整到岸边。 |
| `material` | 使用 Water 着色器的材质。留空用内置的水。 |
| `cellSize` | 最细一圈几何体的格子大小。 |
| `cells`、`rings` | 海洋的圈:每圈一边多少格,以及有几圈。 |
| `waveHeight`、`waveLength`、`waveSpeed`、`waveDirection` | 波浪(见下)。 |

水体每帧把自己的波浪、格子大小和空间位置写进自己的那份材质副本,所以改字段水立刻就变,几个水体也可以共用同一个材质资源。

## 波浪

四道波峰比波谷更尖的正弦波(`exp(sin(theta) - 1)`),相差几个方向,各自的波长、高度和速度是组件上那四个数的份额。它们会**移动几何体**:着色器按波高抬起每个顶点,片元按同一个公式逐像素取斜率,所以被光照的表面就是画出来的表面,和天空交界的轮廓也随波浪起伏。

波浪在水体自己的空间里度量,沿着它的表面和它自己的上方向,所以倾斜的水体就是倾斜的水。参数以世界单位计:以米为单位的场景用默认值,以厘米为单位的要把长度相应缩放。

## 几何体

**湖泊**是 `cellSize` 大小格子的网格。**海洋**是一圈圈格子数相同的网格,每圈的格子是里面那圈的两倍,中间留出里面那圈的洞,所以它能伸得很远,又把三角形花在近处。它跟着相机、落在所有圈都对齐的格点上,材质的原点同步移动,所以网格在波浪下面移动,而波浪留在世界里不动。

粗的一圈画不出短的波:一个波长不到三格就会闪烁,所以它的顶点会淡掉比自己六格还短的波(着色仍然逐像素显示它们)。两圈相接处,粗的一圈沿边的顶点少一半,表面可能在顶点之间分开,分开多少取决于波浪在它们之间做了什么;让 `waveLength` 至少是看得到的最粗一圈的六格,接缝就看不出来。

## 湖泊与岸线

湖泊按它的轮廓裁出形状,波浪知道岸边在哪儿、水有多深。水体在轮廓的包围盒上烘一张小场:到岸边的有符号距离,以及水在它下面的地面之上有多深。从这两个量得出一个点保留多少波浪(在岸边或水很浅处一点不留,从 `shoreWidth` 往里全留),写进网格的顶点,所以几何体向岸边变平静;也写进一张纹理,所以像素也是如此,边缘按轮廓来裁(而不是按网格的格子),岸边还会起泡沫。

场景里有 `Terrain` 且湖面水平时,它下面的地面就是地形:水填满低处,在山丘与它相交的地方被山丘截断(深度测试做到这一点),波浪随变浅而消失。地形一变或湖面一动,这张场就会重建;倾斜的湖,或没有地形的湖,要多深有多深。轮廓不应自相交。

## 河流

河流是沿着它自己实体上的 `Spline`([样条](#样条))铺开的一条带子:沿曲线每隔 `cellSize` 一排横跨水面的顶点,宽度取曲线在那里的宽度,高度取曲线在它下面的高度,所以河流是顺着坡往下流的。在同一个实体上放一个 `Spline` 和一个 `form` 为 River 的 `WaterBody`,场景运行时河流就建出来了。

- **水流。** `flowSpeed` 是河面最宽处的流速;窄的河段更快、宽的河段更慢,范围在它的四分之一到两倍之间,和同样的水流过不同宽度时的情形一致。方向就是曲线的方向。
- **表面随水流动。** 着色器把波浪和涟漪顺流带走:表面的两份拷贝每次沿水流前进一个周期,一份淡入的同时另一份淡出,所以其中一份被放回起点的那一刻被另一份遮住,河道拐弯处表面也不会被拉长。
- **几何体是平的。** 河流的几何体不被波浪抬起(表面画成平的,只在着色里流动),所以河流没有可读回的波浪:`Waters.sample` 给出它的曲线高度、向上的法线,以及 `flow` 里的水流(世界单位每秒,沿河道方向;别处为零)。
- **河岸。** 边缘就是这条带子自己的边,和几何体一样清晰。它和地面相接处的泡沫来自场景深度,和任何岸边一样。

## 漂浮

给一个有 `RigidBody3D` 和碰撞体的实体加上 `Floating` 组件,水就会托住它并带着它走。它通过作用在刚体上的力来工作,力来自询问水面([查询表面](#查询表面))在身体的几个点之下在哪里,所以不需要渲染器:不画任何东西的服务器、测试或构建,漂浮的结果也一样。

| 字段 | 作用 |
|---|---|
| `buoyancy` | 水的密度与物体密度之比。1 表示完全没入时刚好托住;2 表示漂在一半没入的位置。 |
| `drag` | 水对物体穿行的阻力,每秒。它让物体在静水里停下来,在河里随水流前进。 |
| `radius` | 物体上的一个点要在水面以下多深(世界单位)才算完全湿透。 |
| `points` | 物体自身空间里、世界单位的点,水会针对它们作答。把它们散开(比如船体的四个角),波浪就会让它倾斜。留空就是原点那一个。 |

在每个点上,没入水里的份额(水面处为 0,从 `radius` 往下为 1)给出一个逆着重力的浮力 `mass * g * buoyancy * 份额 / 点数`,作用在这个点上,还有一个对抗这个点相对水的速度的阻力(物体自己的速度加上转动在那里带来的,再减去水流)。这些力在每个固定步长、世界步进之前施加。`buoyancy` 为 2 且只有一个点的物体,中心会停在水面以下 `radius / 2` 处。

它需要 3D 物理模块,并且是带有施力函数(`_physics3d_addForce`、`_physics3d_getBodyDynamics`)的那一版;没有这些函数的构建会警告一次,什么也不会漂。漂浮是一个刚体在一种流体里:没有附加质量,没有船体形状带来的升力,完全没入的物体除了水流外不会被推向任何方向。

## 水面之下

当活动相机在一个水体之下时,画面就是水的。水模块每帧报告相机在哪儿(来自 [`Waters.sample`](#查询表面)),后处理体积系统只要相机还在水下,就像天气带来雨一样,加上一个 **Underwater** 效果:

- **按穿过的水雾化。** 每个像素的光穿过了从眼睛到它出处的距离(天空没有表面,取水能被看穿的最长距离 `u_range`),水按颜色把光吸走,红色最先,用的是和水面材质绘制时相同的 `u_absorption` 和 `u_density`,再还给你它自己的颜色。水下一面白墙是蓝绿色的,远的比近的更甚。
- **越深越暗。** 水还回来的颜色随相机下沉的深度变暗(`u_lightFalloff`),因为到达它那里的光来自上方。
- **没有突变。** 效果在水面以下的第一段距离里渐入(波高的一半,至少一个单位),所以穿过水面是淡入而不是硬切。
- **你写了就用你的。** 在体积里自己写了 `underwater` 效果的场景,保留它的数值;只会填入相机的深度和它完全没入的程度。

水面本身从下面看是翻过来的,光穿过它的方向也反了:从水里出来,超过临界角(约 49 度)的光线被整个反射,所以上面的水是头顶一扇天空的窗户,窗户之外是水下世界的镜子,菲涅尔项也随之改变。窗户的边缘并不是自己画出来的圆:它就是折射走到尽头的地方。

## 样条

`Spline` 是数据,什么也不画:`points`(每个点是实体自身空间里的 `x`、`y`、`z` 和一个 `width`)和 `closed`。河流读取它实体上的那一个;任何沿路径走的东西都可以用 `SplineCurve` 读它:

```ts
const curve = new SplineCurve(spline.points, spline.closed);
curve.position(s);   // 沿曲线走过 s 距离的那个点
curve.tangent(s);    // 那里的前进方向
curve.width(s);      // 那里的宽度,从一个点的宽度平滑过渡到下一个点的
curve.nearest(x, z); // 在 xz 平面上离它最近的地方:s、距离、在哪一侧
```

它是向心 Catmull-Rom 曲线(穿过每一个点,点在一头密、另一头疏时也不会打圈或出尖),按沿曲线的距离来度量,所以曲线上的位置是离起点 `s` 个单位,而不是在点靠得近的地方跑得很快的参数。开放曲线越过两端就停在端点;闭合曲线会绕回去。样条是一个可选模块(`esengine/spline`)。

## 查询表面

`Waters.sample(x, y, z)`(资源 `WatersRes`)为包含这个点的水体作答:

- `depth`:这个点沿水体上方向高出表面多少(在下面则为负),世界单位;
- `normal`:表面在那里的法线,世界空间;
- `surface`:这个点正上方或正下方、表面上的世界坐标;
- `inside`:这个点是否在水体范围之上:在湖泊轮廓之内或河岸之间(海洋没有轮廓,所以总是);
- `flow`:水在那里怎么流动,世界单位每秒(河流的水流;静水为零)。

它读的是着色器画的同一个公式,取这一帧的时间。水体的位置、旋转和均匀缩放都被考虑进去。`Waters.heightAt(x, z)` 是未倾斜水体的简写。点上方没有水则返回 `null`。

代码读到的是完整的波浪和;海洋远处的粗圈画得少一些(见上),所以在接近地平线处两者可能相差那些短波,它们本来就很小。

## Water 着色器

`builtin:water` 也可以单独用在任何网格上,这是组件出现之前做一块平水面的方式。`u_waveSpace` 取默认值(0)时,波浪按世界的 xz 平面度量,什么也不抬起,表面被当作是平的。组件把它设为 1(网格的 uv 是它的局部 x 和 z),使用水体自己的空间。

- **波浪。** `u_waveLength`、`u_waveHeight`、`u_waveSpeed`、`u_waveDirection`;小涟漪(`u_rippleStrength`、`u_rippleLength`)骑在它们上面,并随距离淡出,所以远处的水是平静的而不是闪烁的。
- **折射与水深。** 水下看到的是不透明场景的画面,被波浪按水量多少偏移。水深是**量出来的**:绘制水之前,帧会拷贝一份场景每个像素离眼睛多远,水在某个像素处的深度就是那个距离与水面自己的距离之差。光沿着这段水柱被吸收——红色最先(`u_absorption`、`u_density`)——水再还给你它自己的颜色,随水变深从 `u_shallowColor` 过渡到 `u_deepColor`。
- **反射。** 天空、灯光和环境按菲涅尔项反射(水是 1.333),所以俯视时清澈、掠射时像镜子。想要场景本身的倒影,在体积里加上屏幕空间反射。
- **泡沫。** 水柱浅于 `u_foamWidth` 的地方(岸边、礁石、桥墩脚下)和波峰上(`u_foamCrest`)出现泡沫,由流动的噪声打散。

## 限制

还没有的部分,免得让人意外:

- 它需要与玻璃相同的、由引擎拷贝的场景(有后处理链在运行),以及渲染目标能存浮点数的设备来存深度。没有链时,水作为半透明表面画在场景上;没有浮点目标时,深度处处是 `u_fallbackDepth`,所以没有岸边泡沫,颜色也不随水深变化。
- 与玻璃一样,它只折射不透明场景:透过它能看到船体,但看不到另一个透明表面。
- 河流不会切削地面,急流和瀑布不会按水流的快慢或陡度起泡沫,两个水体相接处也不会融合。湖泊的轮廓是平面上的多边形:它不跟随弯曲的岸线,波浪向岸边消失而不是在岸上破碎。
- 东西可以漂浮(见[漂浮](#漂浮));还没有东西能游泳,水里的物体也不会激起涟漪或尾迹。
- 水下有雾和染色,但没有光:水下的物体上没有焦散,没有穿过水面的阳光束,从下面看水面时镜子里映的是雾,而不是水自己的画面。相机整个在水下或整个不在:镜头上没有横过的水线。
- 它不会对穿过它的东西作出反应:没有涟漪,没有尾迹。
- 波浪是这四道波峰尖的正弦,不是波谱,并且只把表面抬起,不会把它推向一侧。
