title: Project settings

Open settings with **Ctrl / ⌘ + ,** or the Activity Bar's gear. The window has two tabs,
**Editor** and **Project**, and each is a short list of pages. Search at the top finds a
setting on any page.

- **Editor** — yours, kept on this machine:
  - **General** — Appearance (**language**, accent color, interface font, UI scale),
    Performance, Console, and the renderer backend.
  - **Viewport** — grid, snapping, and the transform gizmos.
  - **Shortcuts** — every shortcut below is rebindable here.
  - **Tools and AI** — the external script / image editors and browser, and the
    built-in [agent](/docs/agents/built-in/): keys, models and endpoints of your own.
- **Project** — saved into `project.esproject` and shared with whoever opens it:
  - **Game** — **Display** (the project design resolution, which seeds new Canvases and
    drives the device preview in any scene; the project-wide **screen orientation**, which
    every export target honors and which, unset, is derived from the design resolution's
    aspect; and the **camera fit**, how the main camera scales the design resolution
    without a UI Canvas — `None` = off), **UI** (the widget **theme**, dark or light, and
    per-role **Theme Colors** overrides, applied identically in the editor, Play, and every
    export — see [UI widgets — theming](/docs/ui/widgets/#theming)), **Audio** and **Spine**.
  - **Rendering** — up to thirty-two named sorting layers that populate the inspector's
    layer dropdown, and which of them y-sort. The names are suggestions, not a limit:
    a render `layer` still accepts a number outside them. Quality tiers and the project
    environment live here too.
  - **Physics** — enable, gravity, sixteen collision-layer names and a 16×16 collision
    matrix, plus solver tuning (fixed timestep, sub-steps, contact Hz/damping/push
    speed, sleeping, continuous collision). See [Physics](/docs/gameplay/physics/).
  - **Build and modules** — per-target packaging metadata (WeChat AppID, Desktop app id /
    product name, splash, achievements) and the engine modules the project includes.

Settings you set once and then leave alone — screen presets, solver tuning, the theme's
colors, the module switches, the endpoints of your own AI providers — sit under a page's
**Advanced** fold, so a page's body is what people actually touch.

## Editor language

The editor ships in **English** and **简体中文** and follows your system language on
first launch. Switch it under **Settings → Editor → General → Appearance → Language** — the change
applies after a reload (the editor prompts for one). The editor's UI strings run on
the same [localization engine](/docs/assets/localization/) your game uses at runtime.
