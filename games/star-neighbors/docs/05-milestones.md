# 原型里程碑与验收

日期：2026-10-22。已建立本地模块化结构与交互样区，完成有限的无界面 Web 检查。M1 尚未全部验收，M2–M5 未实现。按依赖推进，不预设发布日期。

## 1. 交付次序

| 阶段 | 交付内容 | 通过条件 |
| --- | --- | --- |
| M0：方向确定 | 三张独立风格图、玩法草案、决策记录 | 用户选定主风格；关键规则明确标为确认或待测 |
| M1：空间与操作样区 | 可行走的 3D 地表、角色、基础建筑预览；2D 建造菜单与星图雏形 | 网格、尺度、碰撞、镜头、地表区块加载可验证；形成球面方案结论 |
| M2：两颗家园互访 | 两个独立玩家、两颗持久星球、传送与授权共建 | 主人退出后访客仍可合法访问；重连和重启保留状态 |
| M3：探索与新家 | 三个尺度档、发现信息、认领与主星切换 | 起始资源有保障；认领不冲突；切换主星保留旧家 |
| M4：共同工程与轻事件 | 会客站材料交付、阶段变化、磁雾花季与安全返程 | 分地/异步参与有效；重试不重复消费；退出保留成果 |
| M5：体验与承载 | 小规模真实玩家观察、模拟负载、目标设备与 CI 验收 | 有可复现报告；负载和设备范围明确；主要体验问题被处理 |

M1 的空间实验与 M2 的服务端状态设计可在接口约定后交错推进；不应先实现长篇单机内容再补持久化多人。

## 2. 核心验收案例

| 编号 | 场景 | 应有结果 |
| --- | --- | --- |
| AC-01 | 玩家首次进入 | 有唯一身份与初始星球，安全落点和基础资源可达 |
| AC-02 | 两位朋友互访 | 地址一致，看到同一份建筑和生态状态 |
| AC-03 | 同时占用一个放置位置 | 只有一次建造成功，失败方不扣料 |
| AC-04 | 主人离线，协作者继续建造 | 合法工作成功，成果能被之后上线的主人看到 |
| AC-05 | 建造/取物权限被撤销 | 新请求按最新权限拒绝，已确认成果不被无故撤回 |
| AC-06 | 传送时断线并重连 | 玩家位置可恢复，库存不丢失不复制 |
| AC-07 | 两人同时认领同一星球 | 归属唯一，另一方获得可理解结果 |
| AC-08 | 认领大星球并切换主星 | 新地址生效，旧家及其建筑保留 |
| AC-09 | 离线生产、满仓、重复唤醒 | 正确结算一次，容量与输入约束有效 |
| AC-10 | 重复/并发交付项目材料 | 消费及进度只生效一次，超出需求部分留在原库存 |
| AC-11 | 忽略或中途退出环境事件 | 不丢物品、经验或家园，无强制后续任务 |
| AC-12 | 服务重启 | 星球尺度/种子/归属、建筑、物品和项目状态恢复 |
| AC-13 | 跨地表区块行走与建造 | 无裂缝、重复交互或双重实体所有权 |
| AC-14 | 区域达到测试容量 | 明确等待/替代目的地提示，无静默吞请求 |

## 3. 体验观察

首轮建议邀请少量玩家分组观察，人数仅用于试验；每轮记录设备、网络、版本与任务。测量第一次放置、第一次见到朋友、第一次共同成果和第一次发现新星球的时间，以及求助次数。

重点访谈：玩家是否有明确归属感；是否愿意主动拜访；帮朋友是否像额外负担；随机拿到小星球是否觉得吃亏；返程是否让人安心；游戏结束时是否自然产生下次想做的事。

这些观察只用于发现问题，小样本不能推断长期留存率。社交质量不能仅用在线时长或资源产量评价。

## 4. 负载与故障试验

先验证少量真实连接，再增加模拟玩家和区域数。分别测试分散访问、集中会客、密集建设、机器生产、频繁传送和断线重试。

每次报告环境、活跃区域、实体/建筑/机器数量、状态更新频率、帧/模拟耗时、P50/P95/P99 延迟、带宽、内存、错误率和保存延迟。单机单进程结果不推导为跨机水平扩展证据。

增加机器/分区后，要重新验证权威归属、跨区一致性和存储热点。容量目标在样区测量后决定，未验证前不对外承诺固定最大人数。

## 5. 验证约束

遵循仓库要求：本地只使用真正无界面的浏览器或 CLI 检查，不启动编辑器、Electron 窗口或其他可见应用进行验证。编辑器验收放在 CI；Web、小游戏和真实设备分别记录证据。

此次策划交付只检查文件、链接、图片存在性、编码和 Git 差异；不运行与文档无关的引擎全量测试。风格候选的视觉审阅不等于引擎渲染验收。

2026-10-22 文档交付检查：7 份 Markdown 与 3 份完整图像描述通过 UTF-8 和文本格式检查；21 个本地文件引用全部有效；3 张独立 PNG 可解码并已进行视觉审阅。A 图为简化轮廓与材质后的候选，B/C 保留各自绘本与工业方向。尚未开展游戏功能、编辑器、设备或承载验收。

## 6. 暂未解决的问题

当前试作证据见 [模块化制作约定](07-modular-production.md)。已验证建筑部件、网格占地、镜头、2D 按钮与日夜照明；尚未验证角色控制、球面、碰撞移动、动态区块加载、星图和设备性能，因此不将 M1 标为完成。

- 球面地表的移动/重力/分块与大型星球尺度如何共同实现。
- 随机尺度分布、正式持有数量、扩展政策和长期存储成本。
- 最终美术风格、角色比例、资产规格及目标硬件。
- 一处会客区域的实际人数、建筑与机器预算。
- 正式账号、部署地区、跨地区延迟与运营方案。
- 生态变化的复杂度，以及如何避免生产和资源收集变成社交负担。
