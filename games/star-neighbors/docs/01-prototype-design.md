# 星邻计划：多人星球原型策划案

日期：2026-10-22。状态：设计草案；主美术参考已确认，细节参数和实际样区待验证。

## 1. 游戏定位

每个人在未来宇宙中拥有一颗自己的星球。玩家经营家园、发现大小不同的新星球、邀请朋友到访，并通过共同工程把个人家园连接为一片有生活气息的星际社区。

核心感受：**我的家值得回来，朋友的世界值得拜访，下一颗星球值得期待。**

主要体验为社交、建造、探索和轻度环境冒险。3D 场景、角色与空间操作，和 2D 星图、建造 UI、物品及社交反馈共同组成体验。PC 键鼠第三人称是原型建议方案，尚未锁定正式发行平台；Web、小游戏及其他设备需要独立性能和操作验收。

## 2. 已确认的方向

| 主题 | 共识 |
| --- | --- |
| 多人 | 从原型开始支持多人合作与持久化，不以房主在线作为世界存在条件 |
| 家园 | 每个人有自己的星球，可授权朋友访问和共建 |
| 宇宙 | 持续扩展，采用分区结构；全宇宙合作不局限于固定小队 |
| 情绪 | 社交优先，正向/中性反馈为主，保留适度风险，尽量少负反馈 |
| 星球 | 尺度随机，可以出门探索寻找更大的星球 |
| 美术 | 采用用户重新指出的初版温暖科幻图，保留自然环境与材质层次，避免进一步幼态化与玩具化；见美术方向文件 |

“无限”是世界生成与扩展方向。实际存储、服务预算和局部实时人数都有边界，必须实测；不承诺无限人同时在同一地点互动。

## 3. 三条设计原则

1. **关系带来内容。** 拜访、礼物、共同建设和异步协作本身有价值，进度无需强迫玩家固定时间组队。
2. **探索提供选择。** 大星球提供空间，小星球提供紧凑的生活与独特风景；基础生存和基础制作在所有起始星球都可完成。
3. **失败保留成果。** 风险产生短期变化和有趣故事；默认规则保护家园、物品与长期建设投入。

## 4. 世界结构

| 层级 | 体验 | 持久内容 |
| --- | --- | --- |
| 宇宙 | 星图、好友、共同项目 | 身份、地址、所有权、发现与全局项目 |
| 星区 | 邻里、公共空间站和活动 | 公共工程、区域发现和访问入口 |
| 星球 | 家园或探索目的地 | 尺度、种子、环境、建筑、生态与授权 |
| 地表区块 | 实际行走、采集和建造区域 | 地形变化、放置物与资源状态 |

好友可以优先安排在相邻星区，也可以直接访问已知地址。个人星球与公共探索星球的权属在星图上明确显示。星图中的轨道预览是全景表达，不应被当成全表面可运行、球面重力已实现的证据。

## 5. 核心循环

### 个人日常

回家查看变化 → 选择今天想做的事 → 采集/种植/建造/探索 → 获得材料、外观或发现 → 改善家园 → 邀请朋友看成果。

### 社交合作

看到朋友的邀请或项目 → 方便地到访 → 承担一个可独立完成的小任务 → 一起看见建设变化 → 保留共同成果和纪念。

### 宇宙探索

发现信号 → 预览未知星球的信息 → 独自或一起探索 → 了解尺度、风景与特产 → 标记、分享或认领 → 根据喜好安排新家。

三条循环互相提供动机。探索可以为朋友带回种子，建筑可以成为集合地点，公共工程可以开启新的探索入口。

## 6. 多人合作的三种形式

| 形式 | 原型例子 | 要求 |
| --- | --- | --- |
| 同时合作 | 两人搭建温室，一人装设备，一人种植物 | 同步状态、明确权限、操作冲突反馈 |
| 分头协作 | 不同星球提供空间站所需材料 | 持久项目进度、贡献一次生效 |
| 异步接力 | 主人下线后，朋友完成被授权的花园 | 无房主依赖、权限可撤回、建设记录 |

伙伴定位采用可随时改变的兴趣分工，如园艺、建筑、发现和运输，不设强制职业门槛。基础制作不因缺少某一职业而锁死。

## 7. 星球尺度与认领

星球尺寸随机是正式方向；实际分布、最小/最大规模和稀有度需要结合生成、性能与体验实验确定。

原型以小、中、大三个尺度档验证发现与选择，抽样权重暂按 40% / 40% / 20% 进行实验，**仅为待验证参数**。大小影响可建设空间、地貌分布和旅行距离，不直接赋予所有资源更高产率。

每颗初始星球保证安全落点、基础材料和早期拜访入口。玩家可以免费探索其他候选星球；大星球的发现不依赖付费刷新。相同宇宙地址始终对应同一颗星球，归属由服务器统一确认。

原型建议允许一颗主星和一颗额外认领星，以验证“找到更大星球并逐步搬家”。切换主星不删除旧家，好友仍能找到原地址。正式占有名额、闲置政策和扩展规则待定。

## 8. 正向反馈与风险

优先反馈：朋友到访、共同建成的设施、环境变美、新植物、新外观、新地点、便捷功能和纪念记录。

风险来自可识别的环境变化和自愿参与的远征。例如磁雾让路线不易辨认，同时出现发光植物；玩家可返回、等待，或和朋友继续寻找。活动失败返回安全点，保留携带物、已发现信息和已完成贡献。

默认原型不设饥饿死亡、死亡掉落、经验倒扣、装备永久损坏、离线拆家或强制每日任务。食物用于可选增益和社交分享；离线生产受到原料与仓储限制，满仓后停止且不损坏。

## 9. 第一版范围

建议原型内容预算：一个共享星区、每位测试玩家的初始星球、三个尺度档的候选星球、一座公共空间站、一个温和天气事件、两种基础地表配色、一个角色基础体和一个维修机器人外形。

功能优先：身份与星球绑定、访问、授权共建、资源转移、星球发现/认领、公共项目、重连/重启后状态保留。美术优先：一个可对照的完整样区，加对应 2D 星图、建筑菜单和物品反馈。

宇宙战争、复杂战斗职业、玩家掠夺、完整交通经济、连续宇宙飞行和全地形自由挖掘不进入这次原型。球面地表与平面分区的衔接先做专项实验，再确定实际探索尺度。

## 10. 第一轮成功标准

- 新玩家目标在 10 分钟内理解星球归属，并能拜访另一位玩家；时间是观察目标。
- 两人能完成一次共同建造，并能说清楚自己贡献了什么。
- 主人离线时，获授权的朋友仍可进入并继续工作。
- 玩家能发现不同尺度星球，认领新地点且保留旧家。
- 失败/返程/重连不会丢失物品或已确认的建设成果。
- 访谈能回答“我为什么想去朋友那里”和“我下一次想做什么”。
