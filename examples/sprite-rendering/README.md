# Sprite Rendering

A space-themed sprite laboratory using CC0 Kenney Simple Space art.

- Eight instances of one white ship texture retain different tints, overlapping draw layers and independent wave motion.
- A station and colored meteors demonstrate orbital motion.
- Four satellite instances retain normal / X / Y / XY texture flips while rotating.
- The lower-right station badge uses SortingGroup to override its children's individual layers while retaining their within-group order.

All scenery, labels and texture references are editable in the scene. See [asset licenses](ASSET_LICENSES.md).
